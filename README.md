# บันทึกแบตเตอรี่ (Android)

แอปบันทึก % แบตเตอรี่ทุกครั้งที่เพิ่ม/ลด พร้อมเวลา ทำงานเบื้องหลังด้วย Foreground Service

## Build ด้วย GitHub Actions
1. สร้าง repo ใหม่ แล้ว push โฟลเดอร์นี้ขึ้นสาขา `main`
2. แท็บ Actions → Build APK → รอเสร็จ
3. ดาวน์โหลด artifact `battery-log-apk` แล้วแตก zip จะได้ `app-debug.apk`
4. ติดตั้งบนมือถือ (อนุญาตติดตั้งจากแหล่งที่ไม่รู้จัก)

## หลังติดตั้ง
- เปิดแอปครั้งแรก กดอนุญาตการแจ้งเตือน
- กด "ตั้งค่าประหยัดแบต" แล้วตั้งแอปนี้เป็น "ไม่จำกัด" เพื่อไม่ให้ระบบฆ่าแอป
